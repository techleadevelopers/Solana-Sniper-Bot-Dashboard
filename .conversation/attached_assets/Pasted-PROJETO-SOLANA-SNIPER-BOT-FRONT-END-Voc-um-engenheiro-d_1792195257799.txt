PROJETO: SOLANA SNIPER BOT — FRONT-END

Você é um engenheiro de software sênior especializado em React,
TypeScript, interfaces financeiras, dashboards de trading e
aplicações em tempo real.

Sua tarefa é desenvolver o FRONT-END completo de um sistema chamado
Solana Sniper Bot, um painel de controle para um bot automatizado
de negociação de tokens recém-criados no Pump.fun, na blockchain
Solana.

IMPORTANTE:
Este projeto terá um back-end independente desenvolvido em Go.
O front-end deverá ser preparado para integrar-se a esse back-end
por meio de uma API HTTP e WebSocket.

Não implemente a lógica de negociação no navegador.
Não assine transações no front-end.
Não armazene chaves privadas no navegador.
Não simule resultados reais como se fossem dados da blockchain.

- Retomar a estratégia.
- Interromper novas operações.

Permitir copiar o endereço mint.

Adicionar paginação ou carregamento incremental.

Atualizar os dados por WebSocket quando possível.

==================================================
9. GERENCIAMENTO DOS RPCs
==================================================

Criar uma página chamada RPC Manager.

O sistema deverá apresentar cinco endpoints candidatos:

1. https://api.mainnet.solana.com
2. https://solana-rpc.publicnode.com
3. https://rpc.ankr.com/solana
4. https://solana.drpc.org
5. https://api.mainnet-beta.solana.com

Esses endpoints são candidatos e podem ter restrições de acesso.
O back-end será responsável por validar sua disponibilidade.

Não considerar automaticamente um endpoint como gratuito,
ilimitado ou adequado para produção.

Para cada endpoint, exibir:

- Identificação.
- URL, com proteção contra exposição de credenciais.
- Estado.
- Latência observada.
- Taxa de sucesso.
- Quantidade de falhas.
- Último teste.
- Erros de rate limit.
- Capacidade de leitura.
- Estado dos testes de envio.
- Estado dos testes de confirmação.
- Papel atual: principal, reserva ou desativado.

Adicionar controles para:

- Solicitar teste.
- Selecionar RPC principal.
- Selecionar RPC de reserva.
- Desativar endpoint.
- Atualizar métricas.

O front-end não deverá executar testes de transação diretamente.

Todas as operações deverão ser solicitadas ao back-end.
